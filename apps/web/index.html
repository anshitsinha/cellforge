Open huge CSVs

Drag in a multi-gigabyte CSV. It's parsed in a background worker straight into typed columns, so the page never freezes.

Formulas

=SUM(E1:E1000), =IF(F2>100, "big", "small"), cell references and arithmetic — the everyday stuff.

Sort in a click

Sorting reorders an index instead of moving data around, so millions of rows sort in a moment.

Select, copy, paste

Range selection with live sum / average / count, and clipboard that works with Excel and Google Sheets.

Undo everything

Every edit, paste and sort can be undone with Ctrl+Z.

Private by design

There's no backend. Your data lives in your browser tab and nowhere else.

How it works

  1. Columnar storage

    Each column is a single typed array. 100M numbers is one Float64Array, not 100M objects for the garbage collector to chase.

  2. Virtualized canvas

    The grid is one <canvas> that paints only the visible cells, so scrolling 100 rows and 100 million costs the same.

  3. Compiled formulas in progress

    Formulas filled down a column are really vector operations. The plan is to compile them to WebGPU compute shaders.
