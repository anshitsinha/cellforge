# Ask the guide

Press **F1** (or choose **Ask the guide (how do I…)…** in the command palette)
and type a question in your own words: "how do I reconcile the bank to the
ledger", "find duplicate invoices", "password protect a file before emailing
it".

The best passages from this guide, the tutorials and the function reference
appear as you type, each with the page and section it's from. Where a passage
names a command, a button runs it straight away.

The search runs on your computer: the guide is part of the app, and nothing
you type is sent anywhere. It understands different forms of a word
(reconcile, reconciling, reconciliation) and the words people use for the same
thing (rec, VLOOKUP, macro, comment, dupe…).

When a local AI model is loaded (see the developer notes on kiln), it will
also write a short answer from the passages it found.
