# Keyboard shortcuts

| Keys | Action |
| --- | --- |
| Arrows, Tab, Enter, PgUp / PgDn, Home / End | Move |
| Ctrl + arrows, Ctrl + Home / End | Jump to the edge of the data |
| Shift + any of the above, or drag | Extend the selection |
| Ctrl + A | Select all |
| Type, F2, or double-click | Edit a cell |
| Esc | Cancel editing |
| Delete | Clear the selection |
| Ctrl + D | Fill down |
| Ctrl + Alt + = (or Ctrl + +) | Insert rows above the selection |
| Ctrl + Alt + − (or Ctrl + −) | Delete the selected rows |
| Ctrl + B / I / U | Bold / italic / underline |
| Ctrl + 5 | Strikethrough |
| Ctrl + \ | Clear formatting |
| Ctrl + 9 / Ctrl + Shift + 9 | Hide / unhide rows |
| Ctrl + 0 / Ctrl + Shift + 0 | Hide / unhide columns |
| Ctrl + PgUp / PgDn | Previous / next sheet |
| Ctrl + C / X / V | Copy / cut / paste |
| Ctrl + Z / Ctrl + Y | Undo / redo |

On a Mac, use **Cmd** instead of **Ctrl**.
