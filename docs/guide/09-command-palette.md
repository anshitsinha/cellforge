# Command palette

Press **Ctrl+K** (Cmd+K on a Mac) anywhere in the sheet and type what you
want: "bold", "freeze", "unhide", "percent", "merge". You don't need the
whole word: `frz` finds **Freeze top row**. Use the arrow keys and
**Enter**, or click. **Esc** closes it.

With nothing typed, the commands you used last come first.

## What's in it

- **Everything on the toolbars and menus**: formatting, number formats,
  borders, merging, inserting, deleting and hiding rows and columns, row
  heights, freeze panes, sorting, fill, paste options, opening and exporting.
  Each shows its keyboard shortcut, so the palette also teaches them.
- **Every action**, listed as `Action: name`. These are the same building
  blocks the toolbar uses (and the same ones the AI will use). Choosing one
  opens a small form: ranges start as your current selection (type another
  like `B2:D40`), and everything else is labelled. **Run** applies it.

Whatever you run from the palette goes through undo like anything else.
